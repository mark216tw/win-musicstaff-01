# MusicStaffViewer 使用指南

本文件說明 MusicStaffViewer 的安裝、日常操作、設定與疑難排解。若想了解程式內部設計，請參閱 [ARCHITECTURE.md](ARCHITECTURE.md) 與 [DESIGN.md](DESIGN.md)。

---

## 1. 取得與啟動

### 1.1 下載

至 [Releases](https://github.com/mark216tw/win-musicstaff-01/releases/latest) 下載：

- `MusicStaffViewer-<版本>-win-x64.zip`：一般 Intel／AMD 電腦。
- `MusicStaffViewer-<版本>-win-arm64.zip`：Windows on Arm 裝置（例如 Snapdragon X 系列）。

### 1.2 安裝

本程式沒有安裝程式。將 zip 解壓縮到任意資料夾（例如 `D:\Apps\MusicStaffViewer`），直接執行 `MusicStaffViewer.exe`。建議解壓到使用者有寫入權限的位置，避免放在 `Program Files` 底下。

### 1.3 系統需求

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 10 1809（build 17763）以上；建議 Windows 11 |
| 執行環境 | .NET 10 Desktop Runtime（x64 或 ARM64，需與程式架構一致） |
| 顯示 | 建議 1280×720 以上；支援高 DPI |
| Windows App SDK | 已包含在發佈檔案中，無需另外安裝 |

發佈檔為**非 Self-Contained**（framework-dependent）版本，若系統缺少 .NET 10 Desktop Runtime，Windows 會提示下載安裝。

### 1.4 啟動參數與單一實例

- 可直接以命令列開啟檔案：`MusicStaffViewer.exe "C:\Scores\song.musicxml"`。
- 程式為單一實例：若已在執行，第二次啟動會把樂譜交給既有視窗開啟，不會多開一個視窗。
- 支援 Windows 檔案關聯／拖放開啟；若檔案格式不在支援清單內會顯示提示。

### 1.5 支援的檔案格式

| 副檔名 | 說明 |
| --- | --- |
| `.musicxml` | 標準 MusicXML 文字檔（UTF-8） |
| `.xml` | MusicXML 或含 `musicxml` 欄位的舊版 JSON 包裝檔 |
| `.mxl` | 壓縮的 MusicXML（ZIP 容器） |

## 2. 開啟樂譜

- 選單「檔案 → 開啟 MusicXML」，或按 `Ctrl+O`。
- 把檔案直接拖放到視窗。
- 從側欄「最愛樂譜」清單點選。
- 由「檔案 → 最近開啟」選擇最近 10 筆仍存在的檔案。

開啟新樂譜時，程式會先保存目前樂譜的閱讀位置，再載入新檔。載入期間會顯示進度狀態；載入失敗時上方會出現錯誤列，說明失敗原因。

## 3. 閱讀與導覽

### 3.1 版面

- 樂譜採固定 1600 DIP 邏輯寬度排版，系統（system）依「每行小節數」自動分配。
- 樂譜頂端顯示原譜標題、副標題、作曲家與版權資訊；此區塊不列入系統數與導覽。
- 大型總譜採 lazy partial 渲染：只繪製目前可見的系統，並預先準備下一個系統，捲動時再解碼畫面。

### 3.2 縮放

- 工具列「放大／縮小」每次調整 5%，範圍 20%–400%。
- `Ctrl+=`／`Ctrl+-`（含數字鍵盤）調整縮放；`Ctrl+0` 回到 100%。
- `Ctrl+滑鼠滾輪` 以畫面中心縮放。
- 「符合視窗寬度」會依可用寬度調整縮放，並在視窗大小改變時重新計算。
- 高倍縮放時，程式會自動以更高解析度重新繪製可見系統，避免畫面模糊。

### 3.3 捲動與拖曳

- 滑鼠滾輪：上下移動樂譜。
- 按住滑鼠左鍵拖曳：上下左右平移樂譜。
- 水平與垂直捲軸固定在視窗右側／下方，不會隨樂譜縮放而位移。

### 3.4 系統與小節導覽

- `Ctrl+PageDown`／`Ctrl+PageUp`：前往下／上一個系統。
- `Ctrl+G`：輸入小節序號（1–N）後跳轉；程式會換算到包含該小節的系統。
- 目錄（工具列「目錄」）：列出 MusicXML 中實際存在的段落（section）與排練記號（rehearsal mark），點選可跳轉。
- 狀態列顯示目前系統／總系統數，以及目前系統的小節範圍。

### 3.5 全螢幕專注模式

- 按 `F11` 或選單「檢視 → 全螢幕」進入；此時隱藏選單、側欄與工具列。
- 按 `F11` 或 `Esc` 離開，會還原原本的視窗大小與位置。

### 3.6 聲部（Parts）

- 工具列「聲部」可勾選要顯示的聲部；至少需保留一個。
- 變更聲部會重新排版，大型總譜可能需要數秒；完成後會盡量保持目前閱讀位置。
- 聲部選擇會與該樂譜的閱讀狀態一起保存。

## 4. 最愛樂譜

- 開啟樂譜後，點工具列星號可加入／移出最愛。
- 左側「最愛樂譜」清單依樂譜名稱排序，目前樂譜會以主題色條標示。
- 在清單項目按右鍵可「從最愛移除」。
- 最愛清單可收合成窄邊條，讓樂譜區取得更大寬度。
- 若最愛檔案被移動或刪除，該筆記錄會保留；檔案恢復後會重新出現。

---

## 5. 匯出 PDF

1. 開啟樂譜。
2. 選單「檔案 → 匯出 PDF」。
3. 選擇儲存位置；程式會逐系統繪製並顯示進度。
4. 完成後可選擇直接開啟 PDF。

匯出特性：

- 紙張可選 A4、A3 或 Letter，於偏好設定中調整；紙張邊界固定 40 pt。
- 系統保留原始相對寬度，並依內容寬度置中。
- 第一頁包含譜面標題區塊（標題、作曲家、版權）；後續頁面只放實際樂譜系統。
- PDF 中繼資料會寫入標題與作曲家。
- PDF 品質可選 2×／3×／4×，與目前畫面縮放無關。

## 6. 偏好設定

按 `Ctrl+,` 或選單「設定 → 偏好設定」開啟。調整後按「套用」才會保存；按「取消」則捨棄本次修改。

| 設定 | 選項 | 說明 |
| --- | --- | --- |
| 顯示模式 | 跟隨系統／淺色／深色 | 跟隨系統時會即時反應系統主題變化 |
| 介面主題 | 黃色護眼／經典藍／森林綠／暮色紫／中性灰 | 每款主題都支援淺色與深色 |
| 樂譜顯示品質 | 標準／高／最高 | 影響畫面繪製解析度 |
| 樂譜顯示比例 | 符合視窗寬度／自訂百分比 | 沒有既存閱讀狀態時的初始顯示比例 |
| 音符間距 | 緊湊／標準／寬鬆 | 對應 AlphaTab 的 spacing ratio |
| 預設每行小節數 | 4–10 | 預設 6 |
| PDF 紙張大小 | A4／A3／Letter | 匯出紙張大小 |
| PDF 品質 | 標準（2×）／高（3×）／最高（4×） | 影響 PDF 匯出解析度 |

樂譜顏色固定跟隨顯示模式：淺色模式使用白底黑譜，深色模式使用深底白譜；跟隨系統時會隨系統主題重新繪製。

## 7. 資料存放位置

| 資料 | 路徑 |
| --- | --- |
| 設定檔 | `%LocalAppData%\MusicStaffViewer\settings.json` |
| 日誌 | `%LocalAppData%\MusicStaffViewer\logs\app-yyyyMMdd.log` |
| 嚴重錯誤 | `%LocalAppData%\MusicStaffViewer\logs\fatal.log` |

- 日誌保留 30 天，單一檔案過大時會自動輪替。
- 程式不會上傳任何資料；所有樂譜與設定都留在本機。

備份或移轉設定時，複製 `settings.json` 即可。若要重置設定，關閉程式後刪除該檔。

## 8. 疑難排解

| 現象 | 可能原因與處理方式 |
| --- | --- |
| 啟動時提示缺少 .NET | 未安裝 .NET 10 Desktop Runtime，或安裝了不同架構的版本。請安裝與程式相符的 x64／ARM64 版本。 |
| 雙擊後沒有反應 | 確認 Windows 版本符合需求；查看 `fatal.log` 是否有啟動例外。 |
| 樂譜載入失敗 | 確認檔案是有效 MusicXML；`.mxl` 需為標準壓縮格式。可先用其他工具開啟確認。 |
| 畫面空白或只有部分系統 | 可能是排版失敗或記憶體不足。按 `F5` 重新載入，或關閉其他大型程式後再試。 |
| 縮放後文字模糊 | 提高「樂譜顯示品質」或稍待高解析度系統重繪完成。 |
| 匯出 PDF 很慢 | PDF 會以高解析度逐系統繪製，大型總譜需要較長時間；可先改用標準品質。 |
| 看不到目錄按鈕 | 目前樂譜沒有段落或排練記號時，目錄按鈕會停用。 |
| 最愛項目不見 | 原始檔案可能被移動或刪除；將檔案放回原路徑即可恢復。 |
| 第二次啟動沒有帶入檔案 | 確認第一個視窗仍在執行；單一實例會把檔案轉交給既有視窗。 |

回報問題時，請附上版本（「設定 → 關於」）、Windows 版本、架構（x64／ARM64）與 `fatal.log` 內容（請先移除敏感資訊）。

---

## 9. 解除安裝

本程式不寫入安裝資訊。關閉程式後刪除解壓縮資料夾即可；若要一併清除設定與日誌，再刪除 `%LocalAppData%\MusicStaffViewer`。
